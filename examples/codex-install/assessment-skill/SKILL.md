# Fixture Assessment

Use the verified dispatch context and its retained guidance. Inspect the fixture's
issue requirements and repository instructions. If a material requirement is missing,
return focused questions; otherwise return a bounded assessment and initial plan.
Record source evidence and completed/remaining investigation in either case.

Submit the supplied assessment-result/v1 contract through dispatchRuntime and
reproduce its returned presentation. Preserve saved model settings and assessment-only
authority. Do not implement changes or publish to GitHub.
