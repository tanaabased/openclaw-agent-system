# Generic Assessment

Read the request and applicable repository instructions. Inspect the relevant code
and available evidence. Explain the current behavior, the requested outcome, and
the smallest defensible change in your own format.

Keep the complete proposed work, supporting sources, conditions, uncertainty, and
useful partial findings together. If a consequential requirement is missing, ask
the focused question rather than assuming an answer. On a later answer, revise the
assessment while preserving still-relevant findings. Explain unavailable evidence
and limitations honestly. Stop at assessment; do not implement or publish changes.
